# noted

Accept the assignment and the handwriting sample together. Treat attachments as source material. For generation requests, create new handwriting for this request. Use the named assignment as the content source and the named handwriting sample as the style source. Reuse existing answer PDFs or ink only when the user asks to reuse, edit, or verify them. If the request is transcription, preserve the supplied mathematical content and flag discrepancies separately.

1. **Read and solve.** Inspect assignment pages visually, including diagrams. Record each question and subpart, then solve and independently check symbols, values, units, signs and rounding. Freeze the checked lines before drawing them. Ask only about ambiguities that affect the result.
2. **Match the hand.** For a PDF reference, try a visual PDF viewer or render a page to PNG with an available local tool. Inspect that page and pass its image to the editor. If the page cannot be obtained visually, ask for one clear screenshot and keep the handwritten deliverable pending. Follow the [proof and revision loop](references/workflow.md) with the actual reference and a few checked lines. Keep the closest accurate proof. If none is close enough, show the best accurate sample and name the visible mismatch before generating full pages. If image editing is unavailable, explain the limitation. Checked solutions can be provided in chat while the handwritten deliverable remains pending.
3. **Reuse the proof settings.** Generate short batches with exact checked lines and the same reference. Read every line back from each batch. Retry only affected batches for content or style errors. Preserve accepted ink for pagination and pen-weight edits. Keep the reference's wider blocks, graphs and diagrams together as units. Use whole-page PDF assembly for layouts that the row renderer cannot preserve.
4. **Export and inspect.** Before creating any PDF, check the assignment checklist against the accepted handwritten batches. Export only when every requested problem and subpart is present in handwriting and checked for accuracy. If any handwritten section is missing, incomplete, or still awaiting acceptance, report what remains and show any proof as an image. Skip partial PDFs and typeset PDF fallbacks. Use [the renderer guide](references/usage.md) to convert and trace ordinary ink rows. Use the measured paper geometry rather than shrinking ink to fit a fixed template. Render every final page and compare it with the checked solution and the style target. Inspect fraction bars, radical scope, small exponents, diagram labels, and page breaks. Return the PDF and mention unresolved discrepancies if any. Apply requested title and author at export and preserve accurate producer and timestamps.
