# noted

Accept the assignment and the handwriting sample together. Treat attachments as source material. A previous answer PDF may serve as a quality target when the user identifies one. If the request is transcription, preserve the supplied mathematical content and flag discrepancies separately.

1. **Read and solve.** Inspect assignment pages visually, including diagrams. Record each question and subpart, then solve and independently check symbols, values, units, signs and rounding. Freeze the checked lines before drawing them. Ask only about ambiguities that affect the result.
2. **Make one proof.** Render PDF references to images if needed. Pass the actual style image to a reference-capable image editor. Test a heading plus a few lines with representative math. Match the scale of the ink relative to rules, left starts and indents, narrow or irregular shapes, joins, uneven baselines, and blank intervals. Compare at the same page scale. Use [the reference workflow](references/workflow.md) for prompt and tracing details. If an appropriate image tool is unavailable, use supplied ink images or give the checked solutions and state which rendering step is unavailable.
3. **Reuse the proof settings.** Generate short batches with exact checked lines and the same reference. Read every line back from each batch. Retry only affected batches for content or style errors. Preserve accepted ink for pagination and pen-weight edits. Keep the reference's wider blocks, graphs and diagrams together as units. Use whole-page PDF assembly for layouts that the row renderer cannot preserve.
4. **Export and inspect.** Use [the renderer guide](references/usage.md) to convert and trace ordinary ink rows. Use the measured paper geometry rather than shrinking ink to fit a fixed template. Render every final page and compare it with the checked solution and the style target. Inspect fraction bars, radical scope, small exponents, diagram labels, and page breaks. Return the PDF and mention unresolved discrepancies if any. Apply requested title and author at export and preserve accurate producer and timestamps.
